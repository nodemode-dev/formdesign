# Demo credits

Nothing in this demo is third-party media. There are no photographs, stock pictures, vendor templates or sample files. "The Island Press", Northlight, the island, the printers and every name and figure are invented; the text is `backend/app/demos/magazine.md`, the template is FormDesign's own `magazine-feature-spread`, and the picture on page 2 is placeholder art drawn by FormDesign's own `backend/app/templates/samples.py`.

`assets/session.js` is a recording of FormDesign's own engine answering the FormDesign window for this demo (see `README.md`), including pictures of the pages drawn by FormDesign's own layout core with the fonts it embeds and the template font library, all listed in `NOTICE.md`. `assets/covers/` holds Home's three demo covers, copied unchanged from `frontend/public/demos/`; they are each demo's first spread as the layout core drew it.

The interface fonts in `assets/` are Inter and JetBrains Mono from @fontsource (OFL 1.1), and the script contains xterm.js (MIT), all listed in `NOTICE.md` with the app's other dependencies.

The app opens the same demo from Home > Demos, Help > Demos and the `ui.demo.magazine` command, from the same material, so this note covers it too.
