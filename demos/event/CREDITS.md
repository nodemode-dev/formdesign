# Demo credits

Nothing in this demo is third-party media. There are no photographs, stock pictures, vendor templates or sample files. Quay Lights, Harbour Hall, the Old Quay, Northlight Bay, the date and the web address are invented; the brief and the copy are in `backend/app/demos/demos.json`, and the template is FormDesign's own `print-poster-event-type`.

`assets/session.js` is a recording of FormDesign's own engine answering the FormDesign window for this demo (see `README.md`), including pictures of the pages drawn by FormDesign's own layout core with the fonts it embeds and the template font library, all listed in `NOTICE.md`. The window's script and the interface fonts come from `demo/assets/`: the fonts are Inter and JetBrains Mono (OFL 1.1) and the script contains xterm.js (MIT), all listed in `NOTICE.md`.

The app opens the same demo from Home > Demos, Help > Demos and the `ui.demo.event` command, from the same brief, so this note covers it too.
