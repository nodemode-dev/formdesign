# Demo credits

Nothing in this demo is third-party media. There are no photographs, stock pictures, vendor templates or sample files. The Harbour Trust, its chair, its boatyard and every figure are invented; the text is `backend/app/demos/harbour-trust.md`, the template is FormDesign's own `report-annual-review`, and both pictures are placeholder art drawn by FormDesign's own `backend/app/templates/samples.py`.

`assets/session.js` is a recording of FormDesign's own engine answering the FormDesign window for this demo (see `README.md`), including pictures of the pages drawn by FormDesign's own layout core with the fonts it embeds and the template font library, all listed in `NOTICE.md`. The window's script and the interface fonts come from `demo/assets/`: the fonts are Inter and JetBrains Mono (OFL 1.1) and the script contains xterm.js (MIT), all listed in `NOTICE.md`.

The app opens the same demo from Home > Demos, Help > Demos and the `ui.demo.report` command, from the same material, so this note covers it too.
